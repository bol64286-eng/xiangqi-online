# 楚河汉界：私人房间联机中国象棋

## 本地运行

安装 Node.js 18+，在项目目录执行：

```bash
npm install
npm start
```

打开 http://localhost:3000，点击“创建私人房间”，复制邀请链接发给朋友。不同网络的玩家需要部署到公网 HTTPS 域名；localhost 仅自己电脑可访问。

## 已有功能

- 服务端随机生成 10 位房间号；房间号不存在时不会自动创建，避免输错进入陌生房间。
- 红黑双方各占一个席位；第三人只能观战。服务器校验所有走棋，阻止越权。
- 刷新、短时断线可使用浏览器本地保存的随机身份令牌重新占回席位；同一身份多页面登录会踢掉旧连接。
- 走棋实时广播、双方在线状态、将死判定、双方同意后悔棋和重新开局。
- 24 小时无人活动且双方离线的房间会被清理。服务器重启会清空所有房间。

## 部署

在 Render/Railway/VPS 上创建 Node Web Service，启动命令 `npm start`，平台自动提供 `PORT`，确保 WebSocket 可用。将 HTTPS 网站链接分享给对手即可跨网络联机。免费服务休眠、服务器重启会清除内存房间；正式长期运营应添加 Redis/数据库持久化和多实例会话管理。

## 注意

邀请链接是进入房间的凭证，知道链接的人可以观战；首次打开的前两位用户会占据红黑席位。房间没有密码，适合朋友间轻量私人对战，不适合机密对局。对局未实现长将/长捉裁决、超时判负和复杂竞赛规则。
